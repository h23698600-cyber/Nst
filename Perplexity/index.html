Perplexity Explorer

See how a real language model (DistilGPT-2) gives a probability to every token, and how those probabilities become one number: perplexity.

1. Type a sentence

What is happening here? The model reads your sentence one token at a time. For each token it tells us: "How likely did I think this token was, given the tokens before it?"

2. Probability of each token → perplexity

Perplexity = (1/P₁ × 1/P₂ × … × 1/Pₙ)1/N. A low probability means a big 1/P, which pushes perplexity up. Lower perplexity = the model found the sentence less surprising.

Step 1: Multiply all the 1/P values: 2 × 1.25 × 10000 = 25000
Step 2: Count the tokens: N = 3
Step 3: Take the N-th root: (25000)1/3 = 29.24
Perplexity ≈ 29.24: on average the model was as unsure as choosing between about 29.24 equally likely tokens.
